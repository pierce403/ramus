# Contributing

Thanks for helping Ramus grow.

## Development setup

- Follow the instructions in `README.md`.
- Keep commits small and focused.
- Run tests for the area you changed.

## Code style

- Python: `ruff` + `pytest`.
- Web: `npm run lint` + `npm run test`.

## Pull requests

- Explain the motivation and what changed.
- Include screenshots for UI changes.
- Document any new env vars.
